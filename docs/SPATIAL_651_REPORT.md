# Spatial 651 Report

- Karnataka ERA5 monthly archive contains 36 valid ZIP-wrapped NetCDF files for 2021–2023.
- Each month contains 31 latitude points by 21 longitude points: 651 cells.
- Native resolution is 0.25 degrees.
- Each monthly file contains 124 hourly time steps.
- Instant variables: temperature, dew point, pressure, u10, and v10.
- Accumulated variables: precipitation and radiation.
- All 36 monthly ZIP members were inspected successfully.
